# Library Management System 📚

A console-based Library Management System developed using C++.

## 📌 About The Project

This project is designed to manage a library's books and members through an interactive menu-driven application.

It allows users to manage book records, register library members, and handle borrowing and returning operations.

## ✨ Features

### 📖 Books Management
- Add new books with titles and authors.
- Remove books by title or author.
- Search for books by title or author.
- Borrow available books.
- Return borrowed books.
- Display all books with their availability status.

### 👥 Members Management
- Register new members.
- Prevent duplicate member registration.
- Remove members who have no borrowed books.
- Search for members.
- Display all registered members and their borrowed books.

## 🚀 How To Run

1. Download the repository.
2. Open the `.cpp` file using Code::Blocks or another C++ IDE.
3. Compile and run the program.
4. Choose an option from the main menu.

**Note:** This project uses `windows.h` and Windows console functions for colored output, so it is designed for Windows.
